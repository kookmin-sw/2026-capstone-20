### 1. 프로잭트 소개
# EBTI

> 행동을 이해하면, 변화가 보입니다.  
> AI와 Human이 함께하는 행동유형 기반 초개인화 멘탈케어 & 성과 코칭 SaaS

EBTI는 Self-Identity(SI), Behavior Intelligence(BI), Happiness Intelligence(HI)를 기반으로  
개인과 조직의 행동 변화, 회복탄력성, 몰입, 협업을 지원하는 AI 기반 디지털 케어 플랫폼입니다.

단순 진단을 넘어  
**진단 → 해석 → 실행 → 협업 → 추적** 의 루프 구조를 통해  
설명 가능하고 지속 가능한 행동 변화를 제공합니다.

## ✨ Key Features
| 기능 | 설명 |
|------|------|
| 🧠 진단 | 행동 문항(FREE/PLUS: 16개, PREMIUM: 100개)과 행복 문항(FREE/PLUS: 20개, PREMIUM: 100개)을 기반으로 24가지 EBTI 유형 코드와 8개 행동 지표·10개 행복 영역 점수를 자동 분석 |
| 📄 해석 | GPT 기반 LLM이 진단 결과를 분석하여 강점·약점·실행 전략이 포함된 맞춤형 리포트 생성 (기본 3P / 심화 5P) |
| 🚀 실행 | 사용자의 목표와 진단 결과를 기반으로 AI가 4주(28일) 단위의 개인 맞춤 실행 계획 자동 설계 |
| 🤝 협업 | 팀원 EBTI 코드를 기반으로 팀 시너지 점수 계산, 최적 팀원 추천 및 팀 자동 편성 지원 |
| 📈 성장 추적 | 진단 결과를 시각화 차트로 제공하여 행동·행복 프로필 변화를 직관적으로 추적 |

## 🎯 Target
- B2B HR / 조직문화 / 리더십 코칭
- B2G 공공 심리지원·예방 케어
- 대학·청년·재도전 프로그램

## 🚀 Vision
사람 중심 AX 시대를 위한  
지속 가능한 행동 변화 & 디지털 케어 인프라 구축
