## <a id="4-key-features"></a>✨ 4. 서비스별 주요 기능

### 1) EBTI Care — B2B 브랜딩 및 세일즈 자동화 채널

명확한 계층 구조(Tree Structure)를 기반으로 정보의 흐름을 설계하여, 사용자 유형(기업/개인)에 최적화된 맞춤 탐색 경험을 제공합니다.

| 기능 | 상세 설명 |
|:---:|:---|
|  **메인 랜딩** | 서비스 코어 메시지 전달 및 브랜드 신뢰도 확보 |
|  **Business 섹션** | 기업·기관 대상 B2B 도입 가치 및 사례 전달 |
|  **Individuals 섹션** | 개인 사용자 대상 성장 프로그램 안내 |
|  **About 섹션** | EBTI 브랜드 철학 및 핵심 이론 소개 |
|  **Programs 섹션** | AX·HX 프로그램 구조 및 커리큘럼 안내 |

### 2) EBTI Hybrid Hub — SaaS 기반 실행 중심 성장 플랫폼

|  기능 | 상세 설명 |
|:---:|:---|
| **AI 맞춤형 진단** | 요금제 가드 기반 동적 문항 분기 (36문항 / 200문항) |
|  **PDF 보고서 자동 생성** | 최대 3만 토큰 심층 분석 기반 고품질 개인 리포트 |
|  **28일 AI 액션플랜** | 캐릭터 '솔밤'과 대화형 인터페이스로 행동 플랜 수립 |
|  **AI 팀빌딩 추천** | 24×24 궁합 매트릭스 기반 상호보완적 팀원 실시간 추천 |
|  **성장 흐름 분석** | 과거·현재 데이터 교차 분석 및 누적 레이더 차트 시각화 |
|  **관리자 대시보드** | 전체 가입자 및 매출 통계 실시간 모니터링 (대표 전용) |
|  **Toss 결제 시스템** | V2 Webhook 기반 트랜잭션 검증 및 구독 플랜 관리 |
|  **보안 인증** | JWT + Spring Security 기반 Role/Plan 다중 가드 |

## <a id="5-tech-stack"></a>⚙️ 5. 시스템 아키텍처 및 기술 스택

### 🏗️ 시스템 구조도 (System Architecture)
- **Client Layer:** EBTI Care (Cloudflare Pages 호스팅 / SEO 최적화) & EBTI Hybrid Hub (Vercel 배포 / App Router 라우팅 가드)
- **API Gateway & Proxy:** Nginx Reverse Proxy를 통한 HTTPS 보안 강화 및 로드 밸런싱.
- **Backend Layer:** Spring Boot API 서버 기반 도메인 중심 아키텍처 설계, 보안(Spring Security + JWT) 및 결제 트랜잭션 보장.
- **AI Agent Layer:** FastAPI 프레임워크 기반 독립 AI 서버. LangChain 파이프라인(진단, 해석, 실행, 팀빌딩, 추적 에이전트).
- **Data & Storage:** AWS RDS (PostgreSQL 17), Redis 7.0, AWS S3.

## <a id="6-user-flow"></a>🚀 6. 사용 방법 (User Flow)

### 🌐 EBTI Care — 탐색 및 문의

```
① 가치 탐색    EBTI Care의 철학과 운영중인 프로그램 탐색
      │
② 도입 신청   도입하기 버튼으로 담당자에게 문의메일 보내기
      │
③ 플랫폼 연동   'EBTI HybridHub에서 진단받기' 버튼 클릭 → 메인 플랫폼으로 유입
```

### 💻 EBTI Hybrid Hub — 진단 및 조직 관리

```
① 가입 및 결제    카카오/이메일 소셜 로그인 → Toss Payments로 구독 플랜 선택
      │
② 문항 진단      플랜에 따른 진단 수행 (Basic: 36문항 / Premium: 200문항)
      │
③ 결과 확인      웹 결과 화면 + 다운로드 가능한 심층 PDF 보고서 확인
      │
④ 목표 설계      목표를 설정하고 28일 주간/일간 행동 플랜 생성
      │
⑤ 팀빌딩         수업 조직 개설 및 초대 코드 발급 → 팀 생성 → AI 최적 팀원 추천 초대 + 팀 시너지 분석
      │
⑥ 성장 추적      재진단 기반 성장 흐름 관리
```

├── frontend/                # 프론트엔드 통합 레포 (Care & Hybrid Hub)

│   ├── components/          # Styled-Components 재사용 UI 시스템
│   └── styles/              # 테마(Theme) 및 글로벌 스타일
├── backend/                 # 백엔드 API 서버 레포 (Spring Boot)
│   ├── src/main/java/com/ebti/be/
│   │   ├── common/          # 전역 응답 구조 및 Exception Handler
│   │   ├── global/          # Spring Security 및 JWT 토큰 가드
│   │   ├── infra/           # AWS, Redis, Toss Payments 연동
│   │   └── domain/          # 회원, 진단, 팀빌딩 비즈니스 로직
│   └── build.gradle         # 빌드 및 의존성 관리
├── ai-server/               # AI 에이전트 독립 서버 레포 (FastAPI)
│   ├── app/                 # 5대 목적별 AI 에이전트 파이프라인
│   ├── models/              # 프롬프트 템플릿 및 LLM 연결
│   └── requirements.txt     # 파이썬 가상환경 의존성
└── README.md                # 통합 프로젝트 리드미
