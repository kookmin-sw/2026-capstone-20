## <a id="1-architecture"></a>🏗️ 1. 프로젝트 아키텍처 & 고객 순환 루프

본 프로젝트는 독립적인 목표와 타겟팅을 가진 두 개의 개별 서비스 웹페이지로 구성되어 있습니다. 두 서비스는 상호 유기적으로 결합되어 **[유입 → 신뢰 형성 → 실증 체감 → 계약 및 안착]**으로 연결되는 비즈니스 선순환 루프를 완성합니다.

## <a id="2-business-impact"></a>📊 2. 비즈니스 성과 및 검증 (영업 실적 & 사용자 피드백)

**EBTI Care**와 **EBTI Hybrid Hub**는 런칭 직후 실제 비즈니스 환경과 사용자 테스트를 통해 성과와 효용성을 입증했습니다.

###  EBTI Care : 초기 B2B 세일즈 파이프라인 구축
런칭 후 단 **한 달(26.03~04)** 만에 공공/금융/기업 등 핵심 도메인에서 가시적인 영업 성과를 달성했습니다.

*  **12개 기관 실증사업(PoC) 제안 완료**: 지자체, 시중 은행, 대기업 프랜차이즈 등 주요 기관
*  **6대 핵심 산업 도메인 진출**: B2B/B2G 확장이 가능한 비즈니스 모델임을 객관적으로 입증

###  EBTI Hybrid Hub : 실사용자 만족도 검증
대학생 베타 테스터(N=13) 및 교수/HR 전문가 그룹(N=7)을 대상으로 한 실증 테스트에서 **만점에 가까운 긍정 평가**를 확보했습니다.

*  **평균 90% 이상 긍정 평가**: 진단 정확도, 팀빌딩 유용성, UI/UX 편의성 등 주요 지표 (베타 테스터 기준)
*  **전문가 그룹 100% 만족**: 교수 및 기업 담당자 전원(100%)이 조직 내 실무/교육 도입 필요성 및 활용 가능성에 긍정 응답

## <a id="4-tech-stack"></a>⚙️ 4. 시스템 아키텍처 및 기술 스택

### 🏗️ 시스템 구조도 (System Architecture)
- **Client Layer:** EBTI Care (Cloudflare Pages 호스팅 / SEO 최적화) & EBTI Hybrid Hub (Vercel 배포 / App Router 라우팅 가드)
- **API Gateway & Proxy:** Nginx Reverse Proxy를 통한 HTTPS 보안 강화 및 로드 밸런싱.
- **Backend Layer:** Spring Boot API 서버 기반 도메인 중심 아키텍처 설계, 보안(Spring Security + JWT) 및 결제 트랜잭션 보장.
- **AI Agent Layer:** FastAPI 프레임워크 기반 독립 AI 서버. LangChain 파이프라인(진단, 해석, 실행, 팀빌딩, 추적 에이전트).
- **Data & Storage:** AWS RDS (PostgreSQL 17), Redis 7.0, AWS S3.

## <a id="5-user-flow"></a>🚀 5. 사용 방법 (User Flow)

**🌐 EBTI Care (탐색 및 문의)**
1. **가치 탐색:** 메인 페이지와 About 탭에서 AX·HX 프로그램 구조와 핵심 철학 탐색.
2. **도입 신청:** 'EBTI HybridHub에서 진단받기' 버튼을 클릭하여 메인 플랫폼으로 유입.

**💻 EBTI Hybrid Hub (진단 및 조직 관리)**
1. **가입 및 결제:** 카카오/이메일 소셜 로그인 후 대시보드에서 Toss Payments를 통해 구독 플랜 선택.
2. **문항 진단:** 플랜 권한에 따른 맞춤형 진단(36문항/200문항) 수행.
3. **결과 확인:** 실시간 웹 뷰어 및 다운로드 가능한 심층 PDF 보고서 수신.
4. **목표 설계:** 캐릭터 '솔밤'과 대화하며 28일 주간/일간 행동 플랜 수립.
5. **팀빌딩:** 수업 조직 개설 및 초대 코드 발급. 학생 가입 후 성향 조합 매트릭스 분석 및 AI 최적 팀원 추천 확인.
6. **성장 추적:** 재진단 기반 누적 지표 레이더 차트 비교 및 관리.
